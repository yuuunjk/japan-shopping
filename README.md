# 🗾 일본 편의점 도감 · 살 것 체크

일본 여행 전에 보는 **편의점 · 식료품 · 도시 명물 추천템 도감**입니다.
갤럭시/아이폰 세로 화면에 맞춘 모바일 웹앱이고, 홈 화면에 추가하면 앱처럼 열립니다.

👉 https://yuuunjk.github.io/japan-shopping/

## 무엇이 들어 있나

- **56가지 실제 제품** — 세븐일레븐 · 패밀리마트 · 로손 · 칼디커피팜 · 드럭스토어 · 도쿄/오사카/교토/후쿠오카/오키나와/삿포로 명물
- 제품 사진은 각 브랜드 공식 사이트의 실제 상품 이미지를 내려받아 `assets/items/`에 저장 (깨지는 이미지 없음)
- 카드를 누르면 **일본어 원문 이름이 크게** 나옵니다 — 점원에게 화면을 보여 주세요 (복사 버튼 있음)
- 가격(엔) · 파는 곳 · 추천 이유 · 먹는 팁 · 주의할 점
- **🛒 살 것 체크** — 카드의 ＋로 담고, 현지에서 사면 체크(취소선). 폰 안에만 저장됩니다(`localStorage`)
- 한국어 · 일본어 · 매장 · 도시 검색, 카테고리/도시·매장 필터
- PWA: `manifest.webmanifest` + `sw.js` (오프라인에서도 도감이 열립니다)

## 파일

```
index.html                 앱 전체 (데이터 인라인)
manifest.webmanifest       홈 화면 설치용
sw.js                      서비스워커 (앱 셸·상품 사진 캐시)
app-icon-*.png             앱 아이콘 (180/192/512, maskable)
assets/items/*.jpg         제품 사진 56장
screenshots/               검증 스크린샷 (412×915 / 390×844)
```

## 사진·가격 안내

제품 사진과 이름은 세븐일레븐·패밀리마트·로손·칼디커피팜·이토큐에몬·가네후쿠·이시야·도쿄바나나 등
각 브랜드 **공식 사이트의 실제 상품 정보**에서 가져왔습니다. 가격은 2026년 11월 기준 세금 포함
매장가이며, 지역·매장·시기에 따라 달라질 수 있습니다. `약`으로 표시한 가격은 대표 용량 기준입니다.
사진의 저작권은 각 브랜드에 있으며, 이 저장소는 여행 준비용 개인 도감으로만 사용합니다.
